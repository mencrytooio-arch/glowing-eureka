# Assets Setup

## Logo

1. Place your logo file in the `public` folder
2. Name it: `logo.svg` (or `.png`, `.jpg`, `.webp`)
3. Supported formats: SVG (recommended), PNG, JPG, WebP
4. Recommended size: 
   - SVG: Vector format (scales cleanly)
   - Raster: Minimum 200px width, transparent background preferred
5. The logo will automatically display in the header
6. If the logo is not found, the text "MenCryToo" will be displayed as a fallback

## Hero Image (Home Page)

1. Place your hero image in the `public` folder
2. Name it: `hero.jpg` (or `.png`, `.webp`)
3. Supported formats: JPG, PNG, WebP
4. Recommended size: 1920x1080px or larger (wide format works best)
5. The image will appear as a subtle background on the home page hero section
6. If the image is not found, the hero section will display with a neutral background

## Product Images (Shop Page)

1. Place product images in the `public/products/` folder
2. Name them: `product-1.jpg`, `product-2.jpg`, etc.
3. Supported formats: JPG, PNG, WebP
4. Recommended size: 1200x1200px (square format works best)
5. If product images are not found, placeholder backgrounds will be displayed

## Notes

- All assets in the `public` folder are served from the root URL (`/`)
- Use lowercase filenames with hyphens (e.g., `hero-image.jpg` not `Hero Image.jpg`)
- Optimize images before uploading for better performance
- SVG format is recommended for logos as it scales perfectly at any size
