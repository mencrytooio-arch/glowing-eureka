# Image Setup Instructions

## Hero Image

1. Place your hero image in this `public` folder
2. Name it: `hero-image.jpg` (or `.png`, `.webp`, etc.)
3. Supported formats: JPG, PNG, WebP
4. Recommended size: 1920x1080px or larger
5. The hero image will automatically be used as the background

If the image is not found, the hero section will display a gradient background as a fallback.

## Product Images

1. Create a `products` folder inside `public`: `public/products/`
2. Add your product images with these names:
   - `tee-1.jpg` - For "Emotional Honesty Tee"
   - `hoodie-1.jpg` - For "Strength in Vulnerability Hoodie"
   - `crewneck-1.jpg` - For "Authentic Self Crewneck"
   - `longsleeve-1.jpg` - For "Feel It All Long Sleeve"
3. Recommended size: 800x800px (square) for product images
4. Supported formats: JPG, PNG, WebP

If product images are not found, a placeholder will be displayed.

## Image Optimization Tips

- Use WebP format for better compression
- Optimize images before uploading (use tools like TinyPNG or Squoosh)
- Keep file sizes reasonable for fast loading
- Maintain aspect ratios for consistent display
